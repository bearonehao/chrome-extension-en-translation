# Popup 翻译面板 — 页面布局设计

## 页面概述

Popup 是用户触发翻译后看到的核心面板，承载"一键翻译"和"下载结果"两大核心功能。设计遵循极简原则，不冗余。

---

## 1. 初始状态（刚打开 / 有缓存结果）

```
┌──────────────────────────────────────┐
│  🔤 EN → ZH  翻译          ⚙ 设置   │  ← 顶部栏
├──────────────────────────────────────┤
│                                      │
│         ┌──────────────────┐         │
│         │    🚀 开始翻译    │         │  ← 翻译按钮（主操作）
│         └──────────────────┘         │
│                                      │
│   点击按钮提取当前页面文章并翻译        │
│                                      │
├──────────────────────────────────────┤
│  📋 上次翻译: 如何构建RESTful API...  │  ← 缓存提示（如有）
│  ⏰ 2026-08-20 15:30                  │
└──────────────────────────────────────┘
```

**功能模块说明**：

| 编号 | 模块 | 功能 |
|------|------|------|
| ① | 顶部栏 | 左侧显示翻译方向标识 + 标题，右侧 ⚙ 图标跳转设置页 |
| ② | 翻译按钮 | 主操作入口，点击触发内容提取 + AI 翻译 |
| ③ | 缓存提示 | 若存在上次翻译结果，底部显示标题和时间，点击可查看 |
| ④ | 引导文字 | 按钮下方轻提示，告知用户操作方式 |

## 3. 翻译中状态（打字机效果）

```
┌──────────────────────────────────────┐
│  🔤 EN → ZH  翻译          ⚙ 设置   │
├──────────────────────────────────────┤
│  # 如何构建RESTful API                 │
│                                      │
│  > **作者**: John Doe                │  ← 打字机效果：逐字输出中
│  > **原文链接**：https://example.com  │
│                                      │
│  REST（表述性状态转移）是一种软件架构   │
│  风格，它为Web服务的设计提供了一组    │
│  约束和原则。构建一个优秀的RESTful    │
│  API需要遵循以下最佳实践...▌          │  ← 光标闪烁
│                                      │
│                                      │
├──────────────────────────────────────┤
│  ■ 翻译中...  ████████░░ 45%  ✕ 取消 │  ← 底部状态栏
└──────────────────────────────────────┘
```

**功能模块说明**：

| 编号 | 模块 | 功能 |
|------|------|------|
| ① | 内容渲染区 | md-wx 组件实时渲染累积的 Markdown 文本，打字机效果 |
| ② | 闪烁光标 | 文本末尾 `▌` 符号闪烁，模拟打字机效果 |
| ③ | 状态栏 | 左侧显示翻译进度，右侧 ✕ 取消按钮可中止翻译 |
| ④ | 自动滚动 | 内容区自动滚动到底部，始终跟随最新输出 |

| 编号 | 模块 | 功能 |
|------|------|------|

| ③ | 复制按钮 | 一键复制翻译结果（Markdown 源码）到剪贴板 |
| ④ | 下载按钮 | 一键下载为 `.md` 文件到本地 |
| ⑤ | 字数统计 | 显示翻译结果字数 |

## 5. 错误状态

```
┌──────────────────────────────────────┐
│  🔤 EN → ZH  翻译          ⚙ 设置   │
├──────────────────────────────────────┤
│                                      │
│              ⚠️                      │
│          翻译失败                     │
│     API Key 无效，请检查设置          │  ← 错误信息
│                                      │
│         ┌──────────────┐             │
│         │  ⚙ 前往设置   │             │  ← 引导按钮
│         └──────────────┘             │
│         ┌──────────────┐             │
│         │  🔄 重试      │             │
│         └──────────────┘             │
│                                      │
└──────────────────────────────────────┘
```

**功能模块说明**：

| 编号 | 模块 | 功能 |
|------|------|------|
| ① | 错误图标 | ⚠️ 吸引注意 |
| ② | 错误描述 | 简洁明确地说明失败原因 |
| ③ | 设置按钮 | 引导用户修复配置 |
| ④ | 重试按钮 | 允许用户直接重试 |

**常见错误类型**：

| 错误 | 提示文案 |
|------|----------|
| API Key 无效 | "API Key 无效，请检查设置" |
| 网络错误 | "网络连接失败，请检查网络后重试" |
| 额度不足 | "API 额度已用完，请充值或更换 Key" |
| 内容提取失败 | "无法识别页面文章内容，请尝试在其他页面使用" |
| 翻译超时 | "翻译超时，请重试或更换更快的模型" |
