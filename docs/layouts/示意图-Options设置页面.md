# Options 设置页面 — 页面布局设计

## 页面概述

Options 页面是独立标签页，用户在此配置 API 连接和翻译参数。设计遵循"最少配置即可用"原则，仅保留必要设置项。

## 2. 模块详细说明

### 2.1 🤖 AI 模型配置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| API 地址 | 文本输入框 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 支持任意 OpenAI 兼容端点 |
| API Key | 密码输入框 | 空 | 默认隐藏，点击 👁 可切换显示/隐藏 |
| 模型名称 | 下拉选择 | `qwen-plus` | 预设：qwen-plus / qwen-max / qwen-turbo，支持自定义输入 |
| 自定义提示词 | 多行文本框 | 空（可选） | 可覆盖默认翻译 System Prompt |

**交互说明**：
- API Key 输入框默认 `type="password"`，右侧 👁 图标控制显隐
- 模型名称下拉框在获得焦点时允许自由输入（支持未列出的模型名）
- 自定义提示词为空时使用内置默认 Prompt

### 2.2 🌐 翻译偏好

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 目标语言 | 下拉选择 | 简体中文 | 预设：简体中文 / 繁体中文 / English |
| 打字机速度 | 单选组 | 中 | 快（30ms 间隔）/ 中（50ms）/ 慢（80ms） |

**交互说明**：
- 打字机速度用三个并排单选按钮，选中态高亮

### 2.3 🎨 显示设置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 主题模式 | 单选组 | 跟随系统 | 跟随系统 / 浅色 / 深色 |
| 字体大小 | 下拉选择 | 14px | 预设：12px / 14px / 16px / 18px |

**交互说明**：
- 主题模式三个单选按钮，切换后即时预览效果

### 2.4 ⌨️ 快捷键

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 触发翻译 | 快捷键捕获 | `Ctrl+Shift+T` | 点击 ✎ 后进入录制模式，按下组合键自动填入 |

**交互说明**：
- 点击 ✎ 修改后，输入框进入"录制模式"（边框高亮），用户按下键盘组合键自动捕获
- 若冲突则提示"此快捷键已被占用"

## 3. 底部操作

| 按钮 | 功能 |
|------|------|
| 💾 保存设置 | 将当前配置写入 chrome.storage.local，显示"保存成功"Toast（2秒后消失） |
| ↩ 恢复默认 | 将所有字段恢复为默认值，需二次确认 |
