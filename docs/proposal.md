# Chrome 英文网页翻译插件 — 需求文档

## 1. 项目概述

### 1.1 项目名称

Chrome 英文网页翻译插件（chrome-extension-en-translation）

### 1.2 项目简介

一款 Chrome 浏览器扩展插件，帮助用户在浏览任意英文网站时，一键提取当前页面的主要文章内容，将其转换为 Markdown 格式，并调用 AI 大模型进行高质量的中文翻译。翻译结果以类似 ChatGPT 的打字机效果动态展示，提供流畅、沉浸式的阅读体验。

### 1.3 目标用户

- 需要阅读英文技术文档、博客、新闻等内容的开发者及普通用户
- 希望快速获取英文文章中文翻译的读者
- 对翻译质量有较高要求，不满足于传统机器翻译的用户

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 文章内容提取

- 用户在浏览任意英文网页时，点击插件图标或使用快捷键，触发内容提取。
- 插件自动识别并提取当前页面的**主要文章内容**（正文），过滤掉导航栏、侧边栏、广告、评论区等非正文区域。
- 提取的内容应保留原文的层级结构，包括但不限于：
  - 标题层级（h1 ~ h6）
  - 段落（p）
  - 列表（有序/无序）
  - 引用块（blockquote）
  - 代码块（pre / code）
  - 加粗、斜体等内联格式
  - 超链接

#### 2.1.2 Markdown 转换

- 将提取的 HTML 文章内容转换为标准 Markdown 格式。
- 转换规则：
  - 标题 → `#` / `##` / `###` ... 格式
  - 段落 → 纯文本段落
  - 加粗 → `**text**`
  - 斜体 → `*text*`
  - 有序列表 → `1.` / `2.` ...
  - 无序列表 → `-` / `*`
  - 引用 → `> text`
  - 代码块 → ` ``` ` 包裹
  - 行内代码 → `` `code` ``
  - 超链接 → `[text](url)`
  - 分割线 → `---`

#### 2.1.3 图片处理

- 原文中的图片需要被转换为 Markdown 图片格式：`![alt](src)`
- `alt` 文本优先使用图片原有的 `alt` 属性，若无则使用图片文件名或留空。
- `src` 使用图片的原始绝对 URL，确保翻译结果中图片能够正常加载显示。

#### 2.1.4 AI 翻译

- 将转换后的 Markdown 原文发送至 AI 大模型进行翻译。
- 翻译方向：英文 → 中文（简体）。
- 翻译要求：
  - 保持 Markdown 格式结构不变（标题、列表、代码块等标记保留）。
  - 代码块内容不翻译，保持原样。
  - 链接 URL 不翻译，仅翻译链接显示文本。
  - 图片语法 `![alt](src)` 中的 `alt` 可翻译为中文，`src` 保持不变。
  - 专有名词、技术术语尽量保留原文或采用业界通用译法。
  - 翻译风格：准确、流畅、符合中文阅读习惯。

#### 2.1.5 打字机效果展示

- 翻译结果以**逐字/逐句动态输出**的方式展示，模拟 ChatGPT 的打字机效果。
- 用户可感知翻译正在实时进行，而非等待完成后一次性展示。
- 展示过程中，已输出的 Markdown 内容应实时渲染为富文本格式。
- 翻译完成后，打字机效果自动结束，展示完整翻译结果。

#### 2.1.6 本地持久化存储

- 无需历史记录功能。
- 仅需在**本地持久化存储用户最近一次的翻译结果**。
- 存储内容应包括：
  - 文章标题
  - 作者名
  - 原始文章 URL
  - 翻译后的正文（Markdown 格式）
  - 翻译完成时间戳
- 当用户再次触发新翻译时，覆盖上一次的存储结果。
- 用户关闭插件弹窗后再次打开时，若本地有存储的翻译结果，可直接展示，无需重新翻译。

### 2.2 辅助功能

#### 2.2.1 插件入口

- **工具栏图标**：点击 Chrome 工具栏中的插件图标，弹出翻译面板。
- **快捷键**：支持自定义键盘快捷键触发翻译（默认建议 `Ctrl+Shift+T` 或 `Cmd+Shift+T`）。
- **右键菜单**（可选）：在网页空白处右键，提供"翻译此页面"选项。

#### 2.2.2 翻译面板

- 弹出窗口作为翻译结果展示的主要界面。
- 面板布局：
  - **顶部**：操作按钮区（翻译按钮、复制按钮、设置按钮）。
  - **中部**：翻译结果展示区（Markdown 渲染 + 打字机效果）。
  - **底部**：状态栏（显示翻译进度、字数统计等）。
- 面板支持调整大小，适配不同屏幕。
- 支持**深色/浅色模式**，跟随系统主题或手动切换。

#### 2.2.3 复制与导出

- **一键复制**：将翻译后的 Markdown 原文或渲染后的富文本复制到剪贴板。
- **导出 Markdown 文件**（可选）：将翻译结果导出为 `.md` 文件下载到本地。

#### 2.2.4 设置页面

- 插件提供独立的设置页面，用于配置：
  - **AI 模型配置**：
    - API 地址
    - API Key
    - 模型名称（如 `gpt-4o`、`deepseek-chat` 等）
    - 自定义 System Prompt
  - **翻译参数**：
    - 翻译目标语言（默认：简体中文）
    - 翻译风格偏好（如：直译/意译）
  - **显示设置**：
    - 打字机速度（快/中/慢）
    - 字体大小
    - 深色/浅色模式
  - **快捷键设置**：
    - 自定义触发翻译的快捷键

## 3. 输出格式规范

翻译最终输出的内容必须遵循以下格式：

```
# [文章标题]

> **作者**: [作者名]
> **原文链接**：[原始文章URL]

[翻译后的正文]
```

### 格式说明

| 字段 | 说明 |
|------|------|
| `[文章标题]` | 原文的一级标题，若原文无明确标题则提取页面 `<title>` 或 Open Graph `og:title` |
| `[作者名]` | 文章作者，优先从 meta 标签（如 `article:author`、`author`）提取，若无则显示"未知作者" |
| `[原始文章URL]` | 当前页面的完整 URL |
| `[翻译后的正文]` | AI 翻译后的 Markdown 正文内容，保留原始层级结构 |

## 4. 非功能需求

### 4.1 性能要求

- 内容提取 + Markdown 转换应在 1 秒内完成。
- 插件弹出窗口打开响应时间不超过 500ms。
- 打字机效果渲染流畅，不出现卡顿。

### 4.2 兼容性

- 支持 Chrome 浏览器最新稳定版及最近两个大版本。
- 支持 Windows、macOS、Linux 桌面平台。

### 4.3 安全性

- API Key 存储在本地，不对外传输。
- 不向除用户配置的 API 地址之外的任何服务器发送数据。
- 遵循最小权限原则，仅申请必要的浏览器权限。

### 4.4 可用性

- 界面简洁直观，无需学习成本。
- 翻译失败时提供明确的错误提示（如：网络错误、API Key 无效、额度不足等）。
- 支持翻译过程中取消操作。

## 5. 边界与约束

### 5.1 功能边界（不做什么）

以下功能**不在**本项目范围内：

- **全文网页翻译**：不提供类似 Google 翻译的整页译文替换功能，仅针对文章正文内容提取后翻译。
- **划词翻译**：不支持用户在页面上选中一段文字后弹出翻译浮窗。
- **翻译历史记录**：不提供翻译历史列表，不存储多次翻译结果，仅保留最近一次。
- **多标签页同步翻译**：不同标签页的翻译相互独立，不进行跨标签页的状态同步。
- **离线翻译**：必须依赖用户配置的 AI API 进行翻译，不支持离线本地翻译。
- **PDF / 图片内文字翻译**：仅处理 HTML 网页中的文本内容，不处理 PDF 文件或图片中的文字（OCR）。
- **视频字幕翻译**：不处理 `<video>` 元素中的字幕或音轨内容。
- **社交平台动态内容**：对于 Twitter/X、Facebook 等动态加载的时间线页面，不保证提取效果。
- **用户账号系统**：不提供用户注册/登录功能，不收集任何用户身份信息。
- **多设备同步**：翻译结果和设置仅存储在本地，不通过 Chrome Sync 跨设备同步。
- **付费 / 订阅功能**：本插件不涉及任何付费功能，完全免费使用（用户需自行承担 AI API 调用费用）。

### 5.2 设计约束

| 约束项 | 说明 |
|--------|------|
| API Key 安全 | API Key 由用户自行配置并存储在本地，插件不提供默认 API Key，不上传至任何第三方服务器 |
| 用户体验 | 翻译过程需有明显进度反馈，避免用户长时间等待无响应；错误信息需清晰易懂，指导用户如何解决 |
| 隐私保护 | 除用户配置的 AI API 地址外，插件不向任何其他服务器发送数据；不收集用户浏览行为、页面内容等任何隐私数据 |

## 6. 用户交互流程

```
用户浏览英文网页
    │
    ▼
点击插件图标 / 使用快捷键
    │
    ▼
弹出翻译面板，自动开始提取内容
    │
    ├─ 成功 ──► 显示"正在翻译..."，开始打字机效果展示
    │               │
    │               ▼
    │           翻译完成，完整展示结果
    │               │
    │               ├─► 用户可复制结果
    │               ├─► 用户可导出 Markdown 文件
    │               └─► 关闭面板，结果持久化存储
    │
    └─ 失败 ──► 显示错误信息，提示用户重试或检查配置
```

## 7. 项目分期规划

### 第一期（MVP — 最小可行产品）

- 核心内容提取与 Markdown 转换
- AI 大模型翻译
- 打字机效果展示
- 本地持久化存储最近一次翻译结果
- 设置页面（API 配置）
- 标准输出格式

### 第二期（功能增强）

- 快捷键支持
- 右键菜单入口
- 导出 Markdown 文件
- 深色/浅色模式切换
- 打字机速度调节
- 复制富文本格式

### 第三期（体验优化）

- 多语言翻译支持（不仅限于英文→中文）
- 翻译结果对照模式（原文/译文并排展示）
- 自定义 CSS 主题
- 更多 AI 模型平台适配（如 DeepSeek、通义千问等）
- 离线缓存优化

---

## 8. 验收标准

1. 在任意主流英文文章网站（如 Medium、Dev.to、BBC News、Wikipedia 等）上，插件能正确提取正文内容并转换为 Markdown。
2. 图片正确转换为 `![alt](src)` 格式，且图片链接可访问。
3. 翻译结果符合指定的输出格式规范。
4. 打字机效果流畅展示，翻译完成后显示完整内容。
5. 关闭插件弹窗后再次打开，能显示上一次的翻译结果。
6. API Key 配置后翻译功能正常可用，配置错误时有明确提示。
7. 代码块在翻译后保持原样，未被翻译。
